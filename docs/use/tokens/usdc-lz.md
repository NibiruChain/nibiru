## Sai USDC and Legacy USDC.e

The v2.23 migration collected eligible legacy USDC holdings for replacement
with Sai USDC. LayerZero is ending support for Nibiru. This page identifies the
legacy asset; use the [token reference](../../dev/evm/token-contracts.md#query-usdc-balances)
for Sai USDC's address, bank denom, and balance-query examples.
